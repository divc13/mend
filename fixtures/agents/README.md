# Agent / DAO / relayer fixtures

All files here are **REPLAY / SIMULATION** artifacts unless a file states otherwise. None is a live transaction, proposal, signature or marketplace response.

- `coordinator/` — clean and prompt-injection intake.
- `inspector/` — redacted evidence manifest, injection manifest and structured model review.
- `agent-market/` — recorded HTTP routes for platform config, poll/start/message/submit, owner registration/pricing/publish; clean, injected and private-data briefs.
- `dao/` — Sputnik policy (strong and weak) and a deterministically generated approved `FunctionCall` proposal for `dao_authorize`.
- `relayer/` — a NEP-366 signed-delegate fixture and its function-call access-key view. **The signature is a placeholder**: live sponsorship requires real signature verification.

The DAO proposal fixture is generated by `services/dao-watcher/scripts/generate-fixtures.ts`; the relayer fixture by `services/relayer/scripts/generate-fixtures.ts`.
